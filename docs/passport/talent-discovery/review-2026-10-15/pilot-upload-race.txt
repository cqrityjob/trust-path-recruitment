## Root cause and fix
The walk chose the file before the page allowed a choice; the page ignored
it, as it is built to. attachDocument now waits for #sp-evidence-file to be
enabled -- the state a person waits for -- and picks on that input. No
assertion timeout was raised and the product code is unchanged.
