# Protective Security Officer – Sweden (Skyddsvakt) — module blueprint

**Slug:** `protective-security-officer-se` · **Market:** SE · **Legally regulated:** yes
**Validation status:** `design` — no items authored, not assignable.

Skyddsvakt is regulated under Swedish protective-security legislation. Legal-dependent content requires the full legal review gate. Swedish requirements do not apply automatically in any other market.

## Content domains the module must cover

| Domain | Primary Core constructs |
|---|---|
| Protective-security discipline | SCC-02, SCC-09 |
| Access and authorisation control | SCC-02, SCC-07 |
| Vigilance around protected assets | SCC-03, SCC-02 |
| Security zones and boundaries | SCC-02, SCC-11 |
| Anomaly handling | SCC-03, SCC-04 |
| Information discipline | SCC-01, SCC-02, SCC-06 |
| Escalation | SCC-04, SCC-06 |
| Response under pressure | SCC-04, SCC-05 |
| Documentation | SCC-06, SCC-09 |
| Consistency and resistance to informal exceptions | SCC-01, SCC-09 |

Spec 5.2 gives this role 12s on SCC-01, SCC-02, SCC-03, SCC-04, SCC-09 and SCC-11 — the heaviest profile of the three, concentrated on integrity, security awareness, vigilance and accountability.

## Targets

~48 draft items in the bank; ~24 in the first operational form; 12–15 minutes.

## Boundaries

This module is **not** security vetting (säkerhetsprövning) and must never be presented as, or substituted for, one. It measures work-related competency only. Any report wording implying clearance, vetting outcome or trustworthiness as a personal attribute is prohibited.
