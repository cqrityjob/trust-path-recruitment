# Väktare v1 — think-aloud protocol (5–8 candidates)

**Purpose:** the `cognitive_interview` gate on all 50 items. This is a human session
plan, not a system and not a pilot. Nothing here produces a score, a norm or a
validity claim; it produces notes that a named reviewer reads before the shadow pilot.
**Prepared, not run.**

## Who and how

- 5–8 people who could plausibly apply for a Väktare role: at least two with no
  guarding experience, at least one who prefers Swedish, at least one who prefers
  English. No current employees of the pilot organisation.
- One facilitator, one note-taker. 60–75 minutes each. The candidate works through the
  form on a phone (375 px) or a laptop, as they would at home, and says what they are
  thinking as they go. The facilitator does not explain items.
- Consent: the session is about the items, not the person; no answer is recorded
  against their name; nothing from the session reaches any employer.

## Facilitator prompts (use verbatim, in the candidate's language)

- Before each scenario: "Läs högt och säg vad du tänker medan du väljer." / "Read aloud and say what you are thinking while you choose."
- After each scenario: "Vilket svar kändes självklart rätt, och varför?" / "Which answer felt obviously right, and why?"
- Then: "Var det något i hur svaren var skrivna — längd, ton, ordval — som avslöjade vilket som var 'rätt'?" / "Was there anything in how the options were written — length, tone, wording — that gave away the 'right' one?"
- On any hesitation: "Vad menar det här alternativet, med dina ord?" / "What does this option mean, in your own words?"
- After each self-report block of three: "Kändes de här tre som samma fråga?" / "Did these three feel like the same question?"
- Before each free-text item: "Innan du skriver: vad tror du att vi vill veta?" / "Before you write: what do you think we want to know?"

## What the note-taker records, per item

| Field | Values |
| --- | --- |
| Obvious-answer cue | none / length / tone / vocabulary / moral obviousness / other (quote) |
| Comprehension | understood / misread scenario / misread an option (which) / asked for a word |
| Reading burden | read once / re-read / gave up on a sentence (which) |
| Realism | "this happens" / "this would never happen" (why) / "depends on the site" (how) |
| Option misunderstanding | the option the candidate paraphrased differently from its intent |
| Experience bias | "I could not answer without having worked as a guard" / "I answered from other work" |
| Free-text instruction | knew what to write / wrote a principle instead of an event / asked how long / used bullet points |
| Time on item | seconds, roughly |

## Items to watch particularly

- **Tone / length:** a03, a07, b02, d05 (long keys by content); b01 (observation naturally longest).
- **Comprehension:** a05 c, a07 scenario (the instruction sentence), d05 (numbers), b06.
- **Realism:** a03 (person first vs confirmed alarm), a07 (entry decision), d05 (coordination before skipping points).
- **Experience bias:** the whole self-report block; c06, c09, c12, c21 in particular; e03 (non-security example allowed).
- **Free-text instruction:** does "vad du själv gjorde, inte hur du formulerar dig" land? Does anyone write in bullet points after reading that they may?

## Output

One page per candidate (the table above), then one summary page: items where ≥2
candidates named a cue, misread an option, or could not answer without guarding
experience. That summary goes to the named SME with the review pack. It moves no gate
by itself.
